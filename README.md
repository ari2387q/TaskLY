## 🌟 About The Project

Skill Tracker is a productivity-focused application that helps users organize, monitor, and visualize their learning progress across various skills and technologies.

Recently upgraded to **Skill Tracker Pro**, the application now features full project management capabilities including Workspaces, Kanban task boards, milestone tracking, and an interactive calendar. Whether you're preparing for placements, learning a new tech stack, or working toward personal goals, Skill Tracker provides a structured way to measure growth and maintain consistency.

---

## ✨ Key Features

### 🏢 Workspaces & Collaboration
Create isolated workspaces for different domains (e.g., "Software Engineering", "Language Learning"). Invite members and assign admin roles to collaborate on shared skills.

### 📊 Project Management Dashboard
Track your proficiency and progress with a premium dashboard featuring task status distribution, milestone completion rates, and upcoming deadlines.

### 🤖 AI-Powered Motivation
Get fresh, context-aware motivational quotes generated by AI (via OpenRouter) on your dashboard to keep you inspired.

### 🎯 Goal & Task Management
Set learning milestones and break them down into actionable tasks. Manage tasks using a beautiful Kanban board with drag-and-drop-like functionality and priority levels (Low, Medium, High).

### 📅 Calendar View
Visualize your upcoming deadlines and target dates on a custom-built, full-month CSS grid calendar.

### ⚡ Fast User Experience
Built with Next.js App Router and Zustand for blazing fast, optimistic UI updates.

## 🛠️ Tech Stack

### Frontend
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **State Management:** Zustand
- **Styling:** Tailwind CSS + Framer Motion
- **UI Components:** Radix UI / custom components
- **Date Handling:** date-fns

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB + Mongoose
- **Authentication:** Custom JWT Auth
- **AI Integration:** OpenRouter API

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ari2387q/skill-tracker.git
cd skill-tracker
```

### 2️⃣ Configure Environment Variables

#### Backend (`server/.env`):
```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
OPENROUTER_API_KEY=your_openrouter_api_key
```

#### Frontend (`frontend/.env.local`):
```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

### 3️⃣ Install & Run Backend

```bash
cd server
npm install
npm run dev
```

### 4️⃣ Install & Run Frontend (In a new terminal)

```bash
cd frontend
npm install
npm run dev
```

The app will be running at `http://localhost:3000`.
